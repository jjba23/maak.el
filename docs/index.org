* maak.el documentation

~maak.el~ is the Emacs front end to [[https://github.com/jjba23/maak][maak]], and both
are about one freedom: your build is Lisp you can read, change and run.  A Maak
file is a Guile module, a task is a lambda, and ~maak.el~ puts those lambdas one
~M-x~ away.  The guide is split by topic; each page links onward where a topic
continues.

Start with [[file:installing.org][Installing maak.el]] if the package is not on your
machine yet, and with
[[file:using-maak-in-emacs.org][Running your tasks from Emacs]] if it is.  When a prompt
asks something you did not expect, the answer is in
[[file:task-arguments.org][Task arguments]]: it is the page that explains why an
optional argument answered with ~RET~ is omitted rather than passed empty.
